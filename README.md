

# Entrega-de-objetos-perdidos-
Crearé un aplicativo alojado en la web para poder registrar los formularios de los objetos perdidos que han sido entregados (más escalable aún)



Para ejecutar

primero se activa el ambiente:
venv\Scripts\activate

segundo se cambia la ruta:
cd "C:\Users\kevin\OneDrive\Escritorio\Entrega-de-objetos-perdidos-\objetos_reclamados"

por último, ejecutamos el archivo principal:
python manage.py runserver

luego ingresar a http://127.0.0.1:8000/admin para ver el programa ejecutándose
